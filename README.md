# GitHub Editorial Bento Dashboard

A high-contrast, editorial Bento grid dashboard for visualizing GitHub developer profiles, repository statistics, and programming language distributions.

## Tech Stack

- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS v3 with custom design tokens
- **Typography:** Antonio (Display Condensed), Plus Jakarta Sans (Brand/UI), JetBrains Mono (Metrics/Code)
- **Icons & Motion:** `lucide-react`, `framer-motion`
- **Export:** `html-to-image`

## Design Palette (GitHub Theme)

- **Canvas (Cool Gray 1):** `#F2F5F3`
- **GitHub Green (Green 4):** `#0FBF3E`
- **Green Highlights (Green 1–3):** `#BFFFD1`, `#8CF2A6`, `#5FED83`
- **Forest & Deep Green (Green 5–6):** `#08872B`, `#0A241B`
- **Process Black & Charcoal (Gray 5–6):** `#232925`, `#101411`
- **Neutral Grays (Gray 2–4):** `#E4EBE6`, `#B6BFB8`, `#909692`

## Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Production build
npm run build

# Code style linting
npm run lint
```
