# GitHub Editorial Bento Dashboard

A high-contrast, editorial Bento grid dashboard for visualizing GitHub developer profiles, repository statistics, and programming language distributions.

## Tech Stack

- **Framework:** React 19 + Vite
- **Styling:** Tailwind CSS v3 with custom design tokens
- **Typography:** Antonio (Display Condensed), Plus Jakarta Sans (Brand/UI), JetBrains Mono (Metrics/Code)
- **Icons & Motion:** `lucide-react`, `framer-motion`
- **Export:** `html-to-image`

## Design Palette

- **Prussian Blue:** `#0B132B`
- **Space Indigo:** `#1C2541`
- **Dusk Blue:** `#3A506B`
- **Tropical Teal:** `#5BC0BE`
- **Canvas Tint:** `#EEF5F6`
- **Pure White:** `#FFFFFF`

## Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Production build
npm run build

# Code style linting
npm run lint
```
